Rocket Start 기반 동시다발 업무 운영을 시작합니다. rocket-orchestrator를 통해 분류 → 슬롯 → 브리핑 3단계를 실행합니다.

## 업무 목록

$ARGUMENTS

## 입력 형식

각 업무는 **업무명 · 중요도 · 마감일** 3가지를 함께 받습니다. 아래 두 형식 중 무엇이든 허용합니다.

- 줄 단위: `- API 공수산출 | 중요도: 높음 | 마감: 6/13`
- 인라인: `API 공수산출(높음, 6/13), 데이터 병합 모델링(높음, 6/20)`

- **중요도**: 높음 / 중간 / 낮음
- **마감일**: `M/D` 또는 `YYYY-MM-DD`, 없으면 "없음"

## 실행 절차

1. 업무 목록이 없으면 아래를 안내하고 종료하세요.
   ```
   업무를 중요도·마감일과 함께 입력해주세요. 예:
   /rocket
   - API 공수산출 | 중요도: 높음 | 마감: 6/13
   - 데이터 병합 모델링 | 중요도: 높음 | 마감: 6/20
   - 외부 연동 설계 | 중요도: 중간 | 마감: 6/30
   - 리팩토링 | 중요도: 낮음 | 마감: 없음
   ```

2. 업무는 있으나 **중요도·마감일이 일부 누락**되었으면, 막지 말고 그대로 진행하되 오케스트레이터가 누락분을 "미지정"으로 표시하고 보수적 기본값(중요도=중간, 마감=없음)을 적용하도록 넘기세요. 누락된 업무는 완료 보고에서 "보완 권장"으로 표시됩니다.

3. `.claude/rocket/today.md` 파일이 존재하고 `date`가 오늘이면, 새 운영 계획을 다시 짜는 것이므로 덮어쓰기 전 한 번 알린 뒤 진행합니다. 파일이 없거나 과거 날짜이면 바로 진행합니다.

4. `rocket-orchestrator` 에이전트를 호출하세요. 업무 목록은 위의 `$ARGUMENTS` 내용입니다.

5. 오케스트레이터가 3단계(분류 → 슬롯 → 브리핑)를 모두 완료할 때까지 기다리세요.
