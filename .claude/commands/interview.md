모호한 요구·아이디어를 구체적인 브리프로 변환합니다.
질문이 아닌 가설로 시작하고, 최대 3라운드 안에 수렴합니다.

## 입력

$ARGUMENTS

---

## 철학

모호함에는 두 층위가 있다.

- **표층(결핍)**: 알고 있지만 말로 못 한 것 → 질문으로 좁힌다
- **심층(상태)**: 아직 형태가 없는 것 → 예시로 형태를 끌어낸다

가설을 먼저 던지면 동의·거부·수정이 동시에 일어난다.
그 반응에 결핍 정보와 형태 정보가 함께 담긴다.

---

## 실행 절차

### 0. 입력 확인

`$ARGUMENTS`가 비어 있으면 아래를 출력하고 종료하세요.

```
사용법: /interview <막연한 아이디어나 요구>
예시:   /interview 코드가 너무 복잡한 것 같아
        /interview 공부한 내용을 정리하고 싶어
        /interview 반복 작업을 자동화하고 싶어
```

### 1. 분석 (출력하지 않음, 내부 판단)

아래 두 가지를 내부적으로 판단하세요. 사용자에게 출력하지 않습니다.

**도메인 분류:**
- `코드` — 구현·수정·리팩토링·버그
- `학습` — 개념 정리·문서화·노트
- `기획` — 아이디어·구조화·설계
- `자동화` — 반복 작업·도구·스크립트

**모호함 층위 판별:**

| 신호 | 판단 |
|------|------|
| 구체적 단어 있음 ("파이썬", "로그인", "함수") | 표층(결핍) |
| 조건·범위 암시 있음 ("~하면 안 돼", "꼭 ~해야") | 표층(결핍) |
| 추상적 단어만 있음 ("잘", "좋게", "깔끔하게") | 심층(상태) |
| 조건·범위 전혀 없음 | 심층(상태) |
| "잘 모르겠다", 상충하는 단어 혼재 | 심층(상태) |

---

### 2. 라운드 1 — 형태 가설 제시

**표층(결핍)으로 판단한 경우:**

아래 형식으로 형태 가설을 제시하세요.

```
이런 것인가요?

완료되면 [산출물 형태]이 존재하고,
[완료 기준]을 만족하면 끝나는 작업.

맞으면 "맞아요" / 다르면 어떤 부분이 다른지 알려주세요.
```

**심층(상태)으로 판단한 경우:**

가설을 두 개 제시하고 판단을 요청하세요.

```
아직 형태가 잡히지 않은 것 같아서, 두 가지 방향을 제시할게요.

A. [형태 가설 A — 더 구체적인 방향]
B. [형태 가설 B — 더 열린 방향]

둘 중 어느 쪽에 가깝나요? 둘 다 아니어도 됩니다.
```

---

### 3. 라운드 2 — 반응 기반 좁히기

사용자 반응을 받은 뒤 아래 기준으로 진행하세요.

**동의한 경우:** → 라운드 3으로 바로 넘어갑니다.

**수정·거부한 경우:** → 수정된 내용을 반영한 새 가설을 제시합니다.
- 이번엔 가설 하나만 제시
- 이전보다 더 구체적인 완료 기준 포함

**여전히 불분명한 경우 (심층):** → 예시 하나를 직접 제시합니다.

```
예를 들어 이런 결과물이 나오면 됐다고 할 수 있을까요?

[구체적인 예시 — 파일명, 기능, 문장 등]

이 예시가 원하는 방향인지 아닌지만 알려주세요.
```

---

### 4. 라운드 3 — 브리프 확인

지금까지의 반응을 종합해 브리프 초안을 작성하고 확인을 요청하세요.

```
정리하면 이런 작업인가요?

──────────────────────────────────────
핵심 의도:   [한 줄]
제약 조건:   [기술·범위·시간 등]
산출물 힌트: [완료 시 존재해야 할 것]
완료 기준:   [측정 가능한 조건]
──────────────────────────────────────

맞으면 바로 /task로 넘길게요.
다른 부분이 있으면 말씀해주세요.
```

---

### 5. 브리프 출력

확인이 되면 아래 형식으로 최종 브리프를 출력하고 종료합니다.

```
## 인터뷰 브리프

핵심 의도:   [내용]
제약 조건:   [내용]
산출물 힌트: [내용]
완료 기준:   [내용]

──────────────────────────────────────
아래 명령으로 바로 시작할 수 있습니다:

/task [위 내용을 정제한 한 줄 요구사항]
──────────────────────────────────────
```

---

## 운영 원칙

- 라운드당 질문 또는 가설은 **하나만** 제시한다
- 3라운드를 넘어도 수렴하지 않으면 → 심층 모호함으로 확정하고 가장 가까운 형태로 브리프를 출력한다
- 브리프 출력 형식은 interpret-agent 입력 포맷과 동일하게 유지한다
- 사용자가 "그냥 시작해" 또는 "됐어"라고 하면 즉시 브리프를 출력하고 종료한다
